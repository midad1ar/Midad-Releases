# مداد (Midad)

إصدارات مداد الرسمية لـ Windows.

- للتثبيت: نزّل ملف `Midad-Setup-<الإصدار>.exe` من [صفحة الإصدارات](https://github.com/midad1ar/midad-releases/releases/latest) وشغّله.
- يُثبَّت مداد لحسابك دون صلاحيات المدير، ويحدّث نفسه من داخله بعد موافقتك.
- كل إصدار يرافقه `update.json` وتوقيعه `update.json.sig`، ومداد يتحقق منهما قبل أي تحديث.

هذا المستودع للإصدارات فقط، ولا يحتوي على الشيفرة المصدرية.
